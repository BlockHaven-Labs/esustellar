Problem
No documented process for triaging a live incident (e.g. contract bug discovered post-deployment, RPC provider outage), distinct from the disaster-recovery runbook, which covers infra loss, this covers active incident handling.

Acceptance criteria
 Defines severity levels and expected response times per level
 Includes a template for post-incident writeups
